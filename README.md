# My Board Games Preorders

Личное адаптивное веб-приложение для учёта предзаказов настольных игр и Wishlist.

## Публикация на GitHub Pages

1. Создайте **публичный** репозиторий `my-board-games-preorders`.
2. Распакуйте архив и загрузите в корень репозитория файлы `index.html`, `style.css`, `app.js` и `.nojekyll`.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**.
5. В качестве Branch выберите `main`, папку `/ (root)`, нажмите **Save**.
6. Через минуту откройте адрес `https://ВАШ-ЛОГИН.github.io/my-board-games-preorders/`.

## Что есть в версии 0.2

- Адаптивный интерфейс для iPhone.
- Главная, Предзаказы, Wishlist, Добавить, Настройки.
- Добавление, просмотр, редактирование и удаление записей.
- Поиск по названию и заметкам.
- Определение Kickstarter / Gamefound / Lavka / GaGa по URL (эвристика).
- Локальное сохранение в браузере.
- Экспорт и импорт JSON.

## Ограничения

- Данные пока хранятся только в браузере и не синхронизируются между устройствами.
- Импорт сведений, обложек и обновлений с внешних площадок ещё не реализован.
- GitHub Pages публикует статические файлы и не запускает серверный код. Для надёжного серверного импорта в будущем понадобится отдельный backend.

## Обновление

Чтобы обновить приложение, замените соответствующие файлы в репозитории новыми версиями. GitHub Pages опубликует изменения автоматически.

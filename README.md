# My Board Games Preorders v0.3

Личный каталог предзаказов и Wishlist. Интерфейс размещается на GitHub Pages. Cloudflare Worker получает метаданные кампаний и синхронизирует каталог с Cloudflare D1.

## Подключить Cloudflare

Понадобятся аккаунт Cloudflare и поддерживаемая Wrangler версия Node.js. Выполните в папке `worker`:

```sh
npx wrangler@4 login
npx wrangler@4 d1 create board-game-preorders
```

Скопируйте ID созданной базы в `database_id` файла `worker/wrangler.toml` вместо нулевого UUID. Если сайт размещён на другом домене, измените `SITE_ORIGINS` на его origin без завершающего слеша и пути. Для текущего GitHub Pages значение уже задано.

```sh
npx wrangler@4 d1 migrations apply board-game-preorders --remote
npx wrangler@4 deploy
npx wrangler@4 secret put ACCESS_TOKEN
```

На запрос Wrangler введите случайный ключ длиной от 32 символов. Например, сгенерируйте его локально командой `openssl rand -hex 32` и сохраните в менеджере паролей. Ключ нужен только в Cloudflare Secrets и в настройках приложения. Публикуемые файлы GitHub ключа не содержат.

## Обновить GitHub Pages

Замените в корне репозитория `index.html`, `app.js`, `style.css` и `README.md`. Добавьте `.nojekyll` и `.gitignore`. Папка `worker/` содержит всё для отдельного развёртывания в Cloudflare. Её можно хранить в том же репозитории, оставив ключи в Cloudflare.

Откройте сайт и перейдите в «Ещё» → «Облачное хранение». Введите HTTPS-адрес, который выдал `wrangler deploy`, и ключ, затем нажмите «Подключить». Ключ хранится в рамках сессии вкладки. На другом устройстве или в новой независимой сессии введите его снова.

Если каталог D1 пуст и локальный каталог уже содержит записи, первое подключение отправит их в D1. Чистый браузер при подключении скачает существующий каталог из D1. После подключения добавления, изменения и удаления сохраняются локально и отправляются в D1. При конфликте версий приложение попросит явно выбрать локальный или облачный каталог. Кнопки «Загрузить из D1» и «Отправить в D1» заменяют каталог целиком. Перед заменой можно сохранить копию через «Экспорт JSON».

## Импортировать кампанию

На вкладке «Добавить» вставьте ссылку на проект и нажмите «Получить данные». Импорт заполняет только пустые поля. Проверьте результат и нажмите «Сохранить игру». До этого запроса на запись каталога нет.

- [Gamefound](https://help.gamefound.com/article/425-gamefound-public-api) использует публичный API кампаний. API отдельных кампаний поддерживает определённые стадии проекта.
- Kickstarter использует метаданные официального виджета кампании. Если площадка отклонит запрос или изменит формат виджета, приложение сообщит об этом и позволит заполнить поля вручную.
- Начало и конец кампании берутся из источника. Валюта заполняется, если источник явно указал EUR, USD, RSD или GBP. Цена заказа, стоимость и дата доставки заполняются вручную.
- Проверка новостей и статусов кампаний, импорт из магазинов и фоновая синхронизация в эту версию не входят.

Документация: [миграции D1](https://developers.cloudflare.com/d1/reference/migrations/) и [настройка Wrangler](https://developers.cloudflare.com/workers/wrangler/configuration/).

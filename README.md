# My Board Games Preorders v0.3

Личный каталог предзаказов и Wishlist. Интерфейс размещается на GitHub Pages. Cloudflare Worker получает метаданные кампаний и синхронизирует каталог с Cloudflare D1.

## Подключить Cloudflare

Понадобятся аккаунт Cloudflare и поддерживаемая Wrangler версия Node.js. Выполните в папке `worker`:

```sh
npx wrangler@4 login
npx wrangler@4 d1 create board-game-preorders
```

Скопируйте ID созданной базы в `database_id` файла `worker/wrangler.toml` вместо нулевого UUID. Если сайт размещён на другом домене, измените `SITE_ORIGINS` на его origin без завершающего слеша и пути. Для текущего GitHub Pages значение уже задано.

```sh
npx wrangler@4 d1 migrations apply board-game-preorders --remote
npx wrangler@4 deploy
```

В [Google Auth Platform](https://console.cloud.google.com/auth/clients) создайте OAuth-клиент типа Web application. В Authorized JavaScript origins укажите `https://strategdzr.github.io`, без пути. При выборе внешней аудитории в режиме Testing добавьте аккаунт владельца в Test users. Redirect URI и Client Secret для кнопки Google с JavaScript callback не нужны.

Добавьте в окружение Worker `GOOGLE_CLIENT_ID` из Google Auth Platform и `GOOGLE_OWNER_EMAIL` с точным адресом Gmail владельца. Оба параметра задаются в Cloudflare. Worker сверяет подпись Google, издателя, Client ID, срок действия и проверенный Gmail. Старый `ACCESS_TOKEN` больше не даёт доступ.

## Обновить GitHub Pages

Замените в корне репозитория `index.html`, `app.js`, `style.css` и `README.md`. Добавьте `.nojekyll` и `.gitignore`. Папка `worker/` содержит всё для отдельного развёртывания в Cloudflare. Её можно хранить в том же репозитории, оставив ключи в Cloudflare.

Для отдельного развёртывания укажите HTTPS-адрес своего Worker в константе `workerEndpoint` файла `app.js`. На опубликованном сайте нажмите «Войти через Google» и выберите разрешённый аккаунт. Каталог открывается после проверки токена. Токен хранится до истечения срока действия в сессии вкладки. Локальная резервная копия каталога остаётся в профиле браузера и не шифруется.

Если каталог D1 пуст и локальный каталог уже содержит записи, первое подключение отправит их в D1. Чистый браузер при подключении скачает существующий каталог из D1. После подключения добавления, изменения и удаления сохраняются локально и отправляются в D1. При конфликте версий приложение попросит явно выбрать локальный или облачный каталог. Кнопки «Загрузить из D1» и «Отправить в D1» заменяют каталог целиком. Перед заменой можно сохранить копию через «Экспорт JSON».

## Импортировать кампанию

На вкладке «Добавить» вставьте ссылку на проект и нажмите «Получить данные». Импорт заполняет только пустые поля. Проверьте результат и нажмите «Сохранить игру». До этого запроса на запись каталога нет.

- [Gamefound](https://help.gamefound.com/article/425-gamefound-public-api) использует публичный API кампаний. API отдельных кампаний поддерживает определённые стадии проекта.
- Kickstarter сначала использует официальный виджет. Если виджет недоступен, Worker передаёт только публичную ссылку на кампанию в бесплатный API [Microlink](https://microlink.io/api). Резервный источник заполняет только подтверждённые поля. У него есть бесплатная квота, при её исчерпании карточку можно заполнить вручную.
- Начало и конец кампании берутся из источника. Валюта заполняется, если источник явно указал EUR, USD, RSD или GBP. Цена заказа, стоимость и дата доставки заполняются вручную.
- Импорт из магазинов не поддерживается.

## Проверка обновлений

В открытом приложении проверка запускается после входа и синхронизации каталога. Её можно повторить кнопкой «Проверить сейчас» на вкладке «Предзаказы». Браузер читает публичные страницы обновлений Kickstarter и Gamefound через [Reader API](https://jina.ai/reader/). В Reader отправляется только ссылка на публичную страницу кампании. Worker сохраняет обновлённый каталог в D1.

При первой проверке карточка получает до пяти последних видимых публикаций. Последующие проверки добавляют публикации с новыми номерами. В карточке хранится до 30 последних записей. Отслеживаются недоставленные предзаказы. Закрытые публикации и сведения о конкретной посылке недоступны. Публикации не меняют статус и ожидаемую дату доставки автоматически. Фоновых задач нет.

Документация: [миграции D1](https://developers.cloudflare.com/d1/reference/migrations/) и [настройка Wrangler](https://developers.cloudflare.com/workers/wrangler/configuration/).

## Лимиты бесплатного плана

Worker ограничивает размер каталога и ответов источников до 1 МБ и обрывает запрос к источнику через 10 секунд. Для запросов с действующим ключом каждый экземпляр Worker допускает до 12 импортов, 60 чтений и 30 записей каталога за минуту. При превышении возвращается 429 с временем повтора. Счётчики действуют в одном экземпляре, поэтому это защита от всплесков, а не глобальная квота.

Суточные квоты аккаунта применяет Cloudflare. Запросы к Worker учитываются до выполнения кода. При исчерпании суточного лимита строк D1 приложение сохраняет локальную копию и предлагает повторить синхронизацию после 00:00 UTC. Пока аккаунт на Workers Free, Cloudflare отклоняет превышение суточных квот. [Лимиты Workers](https://developers.cloudflare.com/workers/platform/limits/) · [Лимиты D1](https://developers.cloudflare.com/d1/platform/pricing/).
